# 🛡️ CIS Controls v8

Este repositório documenta minhas anotações de estudos sobre os **CIS Controls**, focado na aplicação prática para **Defesa Cibernética (Blue Team)** e **Governança**.

## 🎯 Objetivo
Consolidar conhecimentos sobre governança, hardening e monitoramento de segurança, traduzindo a teoria do framework CIS para cenários práticos de proteção.

## 📚 Conteúdo

[Controle 01] | Inventário e Controle de Ativos de Hardware (Nmap, Discovery) | ✅ Concluído |
[Controle 02] | Inventário de Software e Tratamento de Vulnerabilidades | ✅ Concluído |
[Controle 03] | Proteção de Dados (DLP, Criptografia, LGPD) | ✅ Concluído |
[Controle 04] | Configuração Segura (Hardening, IaC, MDM) | ✅ Concluído |
[Controle 05] | Gestão de Contas (Visibilidade, Senhas Fortes) | ✅ Concluído |
[Controle 06] | Controle de Acesso (MFA, SSO, Zero Trust) | ✅ Concluído |

## 🛠️ Ferramentas & Conceitos Estudados
* **Discovery:** Nmap (Ping Sweep, OS Detection), Wireshark.
* **Proteção de Dados:** BitLocker, VeraCrypt, DLP.
* **Gestão de Identidade:** MFA, SSO, RBAC, PAM (Jump Box).
* **Hardening:** Baselines de Segurança, Remoção de Bloatware.

## 🧠 Metodologia
As anotações seguem o formato de **Active Recall**, incluindo:
1.  Resumo Conceitual.
2.  Aplicação Prática (Comandos e Ferramentas).
3.  **Estudo Dirigido** (Perguntas e Respostas para fixação).
